# 🐍 Python Learning & Web Scraping Portfolio

Bine ai venit pe profilul meu! Acest repository conține parcursul meu practic de învățare în Python, axat pe automatizări, web scraping, gestionare de baze de date și pipelines pentru freelancing.

## 🚀 Tehnologii și Biblioteci Utilizate
- **Python 3** (Fundamente, logică, tratarea erorilor)
- **Requests** (Conexiuni de rețea, tratare status HTTP, timeout)
- **BeautifulSoup4** (Parsing HTML, extragere date complexe)
- **SQLite3** (Stocare structurată a datelor, interogări SQL filtered)
- **CSV** (Export profesional de rapoarte)
- **Git & GitHub** (Version control)

## 📁 Structura Proiectului
- `01_bazele.py` -> `03_functii_logic.py`: Sintaxă, bucle și logică
- `04_primul_scraper.py` -> `05_exercitiu_scraper.py`: Web Scraping de bază
- `06_sqlite_scraper.py` -> `08_paginare_scraper.py`: Integrare baze de date SQLite & Paginare
- `09_export_csv.py` -> `10_scraper_robust.py`: Export date & Tratarea erorilor de rețea (`try/except`)
- `11_fiverr_challenge.py`: **The Ultimate Fiverr Pipeline** (Sistem automatizat cap-coadă)
